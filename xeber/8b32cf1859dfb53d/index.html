Maliyyə Nazirliyinin kollektivi Zəfər Günü münasibətilə Zəfər abidəsini ziyarət edib

8 noyabr 2026, 18:52 · 6 mənbə

Vətən müharibəsində qazanılan tarixi Zəfərin 6-cı ildönümü münasibətilə noyabrın 8-də Azərbaycan Respublikası Maliyyə Nazirliyinin kollektivi Zəfər Parkını ziyarət edib.

Bu xəbəri yazan mənbələr

  • Maliyyə Nazirliyinin kollektivi Zəfər Günü münasibətilə Zəfər abidəsini ziyarət edib Day.Az
  • Mədəniyyət Nazirliyinin kollektivi Zəfər abidəsini ziyarət edib 525.az
  • Ombudsman Səbinə Əliyeva və Aparatın kollektivi Zəfər abidəsini ziyarət ediblər AZƏRTAC
  • İqtisadiyyat Nazirliyinin kollektivi Zəfər Tağı abidəsini ziyarət edib İki Sahil
  • Mədəniyyət Nazirliyinin kollektivi Zəfər abidəsini ziyarət etdi Publika.az
  • Nazirliyin kollektivi Zəfər abidəsini ziyarət edib Bakupost

  • Azərbaycanın Avropaya verilən qazı artırılacaq

  • COP31 çərçivəsində Azərbaycan ilə Qırğızıstan arasında ətraf mühit məsələləri barədə müzakirələr aparılıb
  • YAP Veteranlar Şurasının VIII Qurultaydan sonrakı ilk iclası olub
