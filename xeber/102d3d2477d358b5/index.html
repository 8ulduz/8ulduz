Maliyyə Nazirliyinin kollektivi Zəfər abidəsini ziyarət edib

8 noyabr 2026, 20:50 · 8 mənbə

Vətən müharibəsində qazanılan tarixi Zəfərin 6-cı ildönümü münasibətilə noyabrın 8-də Maliyyə Nazirliyinin kollektivi Zəfər Parkını ziyarət edib.AZƏRTAC xəbər verir ki, nazirlik əməkdaşları tarixi Qələbəmizin rəmzi olan…

  • İqtisadiyyat Nazirliyinin kollektivi Zəfər Tağı abidəsini ziyarət edib AZƏRTAC
  • Maliyyə Nazirliyinin kollektivi Zəfər Günü münasibətilə Zəfər abidəsini ziyarət edib Day.Az
  • Maliyyə Nazirliyinin kollektivi Zəfər Günü münasibətilə Zəfər abidəsini ziyarət edib - FOTOLAR Ordu.az
  • Mədəniyyət Nazirliyinin kollektivi Zəfər abidəsini ziyarət edib 525.az
  • İqtisadiyyat Nazirliyinin kollektivi Zəfər Tağı abidəsini ziyarət edib İki Sahil
  • Mədəniyyət Nazirliyinin kollektivi Zəfər abidəsini ziyarət etdi Publika.az
  • Nazirliyin kollektivi Zəfər abidəsini ziyarət edib Bakupost
